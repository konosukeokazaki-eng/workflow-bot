# プライバシーポリシー

**最終更新日: 2026年10月20日**

株式会社C-mind（以下「当社」といいます）は、Google Workspace Marketplace で提供する「Workflow Bot」（以下「本アプリ」といいます）における、ユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

## 1. 取得する情報

本アプリは、提供機能を実現するため、以下の情報を取得します。

| 情報の種類 | 内容 | 取得方法 |
|---|---|---|
| ユーザー識別情報 | メールアドレス、表示名 | Google Chat および Google OAuth 経由 |
| スペース情報 | Google Chat スペースの ID、名称、参加状況 | Google Chat API 経由 |
| ワークフロー入力内容 | ユーザーがフォームに入力したテキスト、選択肢、日付 | Google Chat ダイアログ経由 |
| 送信日時 | ワークフロー実行のタイムスタンプ | 本アプリにより自動記録 |

本アプリは、ユーザーの個人的なチャット会話、プライベートメッセージ、ファイルの内容を**取得しません**。

## 2. 利用目的

取得した情報は、以下の目的のために利用します。

1. ワークフローの実行（申請、承認、記録）
2. ワークフロー実行履歴の Google スプレッドシートへの記録
3. 承認者への通知および申請者への結果通知
4. 本アプリの運営・保守およびエラー調査
5. 利用統計の分析（匿名化された集計データのみ）

## 3. 第三者提供

当社は、取得した情報を以下の場合を除き、第三者に提供しません。

- ユーザー本人の同意がある場合
- 法令に基づき開示が求められた場合
- 本アプリの運用に必要な範囲で、Google LLC が提供する Google Workspace のサービス（Google Chat、Google スプレッドシート、Google ドライブ）に情報を送信する場合

## 4. 情報の保存場所および期間

- 取得した情報は、本アプリをインストールした組織（Google Workspace テナント）が管理する Google スプレッドシートおよび Google Chat 内に保存されます。
- 当社自身は、ユーザーの情報を独立したサーバー等に保存しません。
- 保存期間は、各組織の管理方針に従います。組織の管理者が削除した場合、情報は Google の仕様に従って削除されます。

## 5. アクセスする OAuth スコープ

本アプリは Google から以下のアクセス権限を取得します。

| スコープ | 用途 |
|---|---|
| `userinfo.email` | ユーザー識別 |
| `spreadsheets` | ワークフロー実行結果の記録 |
| `drive` | バックアップファイルの作成、外部スプレッドシート出力 |
| `chat.spaces.readonly` | 利用可能な Chat スペース一覧の取得 |
| `chat.messages`, `chat.messages.create` | ワークフローカードおよび通知メッセージの投稿 |
| `chat.memberships.app` | スペースへの Bot 追加 |
| `script.external_request` | Google API への HTTP リクエスト |
| `script.scriptapp` | Apps Script 内部機能の利用 |
| `script.send_mail` | 管理者宛のエラー通知メール送信 |
| `directory.readonly` | ユーザーメールアドレスの検証 |

## 6. ユーザーの権利

ユーザーは、自身の情報について以下の権利を有します。

- 情報の開示請求
- 情報の訂正、追加、削除の請求
- 本アプリの利用停止

これらの請求を行う場合は、組織の Google Workspace 管理者または下記のお問い合わせ先までご連絡ください。

## 7. セキュリティ

当社は、取得した情報の漏えい、滅失、毀損を防止するため、以下の措置を講じます。

- Google Cloud Platform の標準セキュリティ機能の利用
- サービスアカウント鍵の適切な管理およびローテーション
- アクセスログの記録および監査
- Apps Script の実行環境における認証・認可の徹底

## 8. 外部サービス

本アプリは以下の外部サービスを利用します。

- **Google Workspace** (Google LLC): [プライバシーポリシー](https://policies.google.com/privacy)

## 9. プライバシーポリシーの変更

本ポリシーの内容は、法令変更、本アプリの機能追加等に応じて変更されることがあります。重要な変更がある場合は、本ページで通知します。
